# Homework 3: Responsive Layout
Algassimu Bangura — My Journey into Cybersecurity

## Files
- index.html: existing Homework 2 content with a Grid layout class added.
- styles.css: linked stylesheet with Grid, Flexbox, and responsive breakpoints.

Keep both files in the same folder and open index.html in Chrome.
The original Unsplash photo requires an internet connection.

## Responsive design
- 320px: one column, stacked navigation, introduction, and goals.
- 768px: horizontal navigation, two-column introduction, and two-column goals.
- 1200px: full-width introduction with Interests and Goals side by side below it.
- Breakpoints: 600px and 1000px. Maximum content width: 1100px.
- Border-box sizing, shrinkable Grid tracks, and flexible image width prevent oversized layout tracks. Long text can wrap.

## Required browser checks before submission
Automated browser testing could not run in the preparation environment because the Chromium download failed. These checks still need to be completed.

1. Open index.html in Chrome.
2. Press F12, then Ctrl+Shift+M (Windows) or Command+Shift+M (Mac).
3. Choose Responsive and enter widths of 320, 768, and 1200 pixels, one at a time.
4. At each width, scroll through the whole page. Confirm all text is readable, the photo fits, and no sections overlap or scroll sideways.
5. Check that About Me, My Interests, and My Goals navigation links work.
6. Confirm the distinct layouts described above appear. Resize across 600px and 1000px to see the changes.
